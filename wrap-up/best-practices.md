# 베스트 프랙티스

> Kiro를 잘 활용하기 위한 팁 모음

## 좋은 프롬프트 작성법

### ❌ 나쁜 예시
```
번역기 만들어줘
```

### ✅ 좋은 예시
```
호텔 고객 이메일을 번역하는 도구를 만들어줘.

기능:
1. 영어/일본어/중국어 이메일 입력
2. 한국어로 번역
3. 문의 유형 분류
4. 답변 생성

디자인: 깔끔하고 전문적인 느낌
```

### 프롬프트 작성 공식

```
[무엇을 만들 것인가] +
[구체적인 기능 목록] +
[디자인/스타일 요구사항] +
[기술 조건 (선택)]
```

## Kiro 활용 팁

| 상황 | 팁 |
|------|-----|
| 결과가 마음에 안 들 때 | "~를 ~로 바꿔줘"라고 구체적으로 요청 |
| 에러가 날 때 | "에러가 났어, 수정해줘"라고 요청 |
| 기능을 추가하고 싶을 때 | 기존 기능을 설명하고 "여기에 ~를 추가해줘" |
| 처음부터 다시 하고 싶을 때 | 새 Spec을 만들면 됨 |
| 디자인을 바꾸고 싶을 때 | "색상을 ~로", "레이아웃을 ~로" 요청 |

## 주의사항

- **민감한 정보 입력 금지**: 실제 고객 개인정보를 프롬프트에 넣지 마세요
- **결과 검증 필수**: AI가 생성한 답변/번역은 반드시 사람이 확인
- **점진적 접근**: 한 번에 너무 많은 기능을 요청하면 품질이 떨어질 수 있음
- **저장 습관**: 중요한 변경 후에는 Git commit으로 저장
