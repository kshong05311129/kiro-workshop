# 왜 비개발자도 가능한가?

> Kiro의 Spec-Driven Development는 "말로 설명 → AI가 실행"하는 구조입니다.

## 기존 방식의 문제

업무 자동화 도구를 만들고 싶을 때 기존에는:

1. 개발팀에 요청서 작성 ⏱️ 1주
2. 개발팀 일정 조율 ⏱️ 2-4주
3. 개발 진행 ⏱️ 2-4주
4. 테스트 & 수정 ⏱️ 1-2주

**총 6-11주** 소요

## Kiro를 사용하면

1. Kiro에게 원하는 것을 설명 ⏱️ 5분
2. AI가 계획 수립 (검토 & 승인) ⏱️ 5분
3. AI가 코드 작성 & 실행 ⏱️ 10분
4. 결과 확인 & 수정 요청 ⏱️ 10분

**총 30분** 🚀

## Spec-Driven Development란?

"스펙 기반 개발"이라는 뜻인데, 쉽게 말하면:

```
여러분이 할 일: "이런 게 필요해요" 라고 설명
Kiro가 할 일: 계획 세우기 → 설계하기 → 만들기
```

### 비유로 이해하기

**인테리어 시공을 맡기는 것과 같습니다:**

| 인테리어 | Kiro |
|----------|------|
| "거실을 모던하게 바꾸고 싶어요" | "고객 이메일 번역 도구가 필요해요" |
| 시공사가 도면 제시 | Kiro가 요구사항 & 설계 문서 제시 |
| 고객이 도면 검토 & 승인 | 여러분이 계획 검토 & 승인 |
| 시공 진행 | Kiro가 코드 작성 |
| 완성 후 입주 | 완성된 도구 사용 |

## 오늘 워크샵에서 만들 것

**호텔 고객 응대 도우미** — 단일 웹 페이지(HTML 파일 1개)로:

- 🌍 외국어 고객 문의를 한국어로 번역
- 📝 문의 유형 자동 분류 (예약/시설/불만 등)
- ✉️ 적절한 답변 자동 생성
- 🔄 답변을 고객 언어로 역번역

> ⚠️ **참고**: 실습에서는 실제 AI 번역 API 없이도 동작하는 데모 버전을 만듭니다. 실제 서비스 연동은 심화 학습에서 다룹니다.
