# Kiro란 무엇인가?

> Kiro는 자연어로 대화하면 AI가 코드를 작성해주는 **스마트 개발 도구**입니다.

## 한 줄 요약

**"만들고 싶은 것을 말로 설명하면, AI가 계획을 세우고 코드를 만들어줍니다."**

## 기존 AI 도구와 뭐가 다른가요?

| | ChatGPT / Copilot | Kiro IDE |
|---|---|---|
| **방식** | 질문하면 답변 제공 | 계획 → 설계 → 실행까지 자동 |
| **결과물** | 텍스트 답변 (복사-붙여넣기 필요) | 바로 실행 가능한 프로그램 |
| **구조** | 대화 한 번에 하나씩 | 전체 프로젝트를 체계적으로 관리 |
| **비유** | 똑똑한 비서에게 물어보기 | 전문 개발팀에게 프로젝트 맡기기 |

## 비개발자에게 왜 유용한가요?

### 1. 코드를 몰라도 됩니다
자연어(한국어)로 "이런 기능이 필요해요"라고 설명하면 됩니다.

### 2. 체계적으로 진행됩니다
Kiro는 무작정 코드를 쓰지 않습니다. 먼저 **요구사항 → 설계 → 작업 목록**을 만들고, 사용자가 확인한 후 실행합니다.

### 3. 실무에 바로 적용 가능합니다
만들어진 도구를 바로 브라우저에서 사용할 수 있습니다.

## 주요 특징

### 무료 사용
GitHub, Google, 또는 AWS Builder ID로 로그인하면 무료로 사용할 수 있습니다.

### VS Code와 동일한 외관
이미 VS Code를 사용해본 적이 있다면 익숙한 환경입니다. 처음이어도 괜찮습니다 — 워크샵에서 하나씩 안내합니다.

### 두 가지 모드

| 모드 | 설명 | 추천 대상 |
|------|------|-----------|
| **Supervised** | AI가 변경할 내용을 먼저 보여주고, 승인하면 적용 | 처음 사용하는 분 ✅ |
| **Autopilot** | AI가 자율적으로 파일을 수정/생성/실행 | 익숙해진 후 |

> 💡 **팁**: 이번 워크샵에서는 **Supervised 모드**로 진행합니다. AI가 뭘 하는지 하나씩 확인하면서 배울 수 있어요.
