# Kiro IDE 인증 (로그인)

> Kiro를 처음 실행하면 로그인 화면이 나타납니다.

## 로그인 방법

### 1. Kiro 실행

설치한 Kiro를 실행합니다.

[스크린샷: Kiro 시작 화면]

### 2. 로그인 방법 선택

세 가지 중 하나를 선택합니다:

- **Continue with Google** — Gmail 계정으로 로그인 (가장 간편)
- **Continue with GitHub** — GitHub 계정으로 로그인
- **Continue with AWS Builder ID** — AWS 계정으로 로그인

[스크린샷: 로그인 선택 화면]

### 3. 브라우저에서 인증

클릭하면 브라우저가 열리고 인증 페이지가 나타납니다. 로그인을 완료하면 Kiro로 자동 돌아옵니다.

### 4. 완료 확인

로그인이 성공하면 Kiro의 메인 화면이 나타납니다.

[스크린샷: 로그인 완료 후 메인 화면]

## 문제 해결

| 증상 | 해결 방법 |
|------|-----------|
| 브라우저가 안 열림 | Kiro 재시작 후 다시 시도 |
| 인증 후 Kiro로 안 돌아옴 | Kiro 창을 직접 클릭 |
| "계정을 찾을 수 없음" | 다른 로그인 방법 시도 |

> 💡 **팁**: Google 계정이 가장 간편합니다. 회사 이메일이 Gmail 기반이라면 그대로 사용하세요.
