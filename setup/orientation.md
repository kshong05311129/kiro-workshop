# 인터페이스 둘러보기

> Kiro의 화면 구성을 간단히 알아봅니다.

## 화면 구성

Kiro는 크게 4개 영역으로 나뉩니다:

```
┌─────────────────────────────────────────────┐
│              상단 메뉴바                       │
├──────┬──────────────────┬───────────────────┤
│      │                  │                   │
│ 사이드│    편집 영역      │   Kiro 패널       │
│  바  │  (파일 내용)      │  (AI 대화창)      │
│      │                  │                   │
├──────┴──────────────────┴───────────────────┤
│              하단 터미널                       │
└─────────────────────────────────────────────┘
```

### 1. 사이드바 (왼쪽)
- 프로젝트 파일 목록
- 폴더 구조 확인

### 2. 편집 영역 (중앙)
- 파일 내용을 보고 편집하는 곳
- 여러 파일을 탭으로 전환 가능

### 3. Kiro 패널 (오른쪽)
- **가장 중요한 영역!**
- AI와 대화하는 채팅창
- Specs, Steering 관리
- 여기에 원하는 것을 입력합니다

### 4. 하단 터미널
- 명령어 실행 결과 확인
- 프로그램 실행 상태 확인

## Kiro 패널 상세

Kiro 패널에는 여러 섹션이 있습니다:

| 섹션 | 역할 |
|------|------|
| **Chat** | AI와 자유롭게 대화 |
| **Specs** | 프로젝트 계획 문서 관리 |
| **Steering** | 프로젝트 규칙 문서 |

[스크린샷: Kiro 패널 구성]

## 자주 사용할 동작

| 동작 | 방법 |
|------|------|
| AI에게 요청하기 | Kiro 패널 채팅창에 입력 |
| 새 Spec 만들기 | Specs 섹션에서 **+** 클릭 |
| 파일 열기 | 사이드바에서 파일 클릭 |
| 결과 미리보기 | HTML 파일 우클릭 → "Open with Live Server" |

> 💡 **팁**: 처음에는 Kiro 패널(오른쪽)만 집중하세요. 나머지는 AI가 알아서 처리합니다.
