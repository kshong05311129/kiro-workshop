# Step 4: 고급 분석 기능 추가

> 채팅으로 분석 기능을 확장합니다 — 실무에서 바로 쓸 수 있는 수준으로.

## 진행 순서

아래 중 원하는 기능을 선택하여 Kiro 채팅에 요청하세요.

### 옵션 A: 전일/전주 대비 분석

```
날짜별 데이터를 비교하는 기능을 추가해줘.

- 선택한 날짜 vs 전일 대비 증감률 (%)
- 이번 주 vs 지난 주 대비 증감률
- 증가는 초록색 ▲, 감소는 빨간색 ▼ 로 표시
- KPI 카드에 증감률 표시
```

### 옵션 B: 요일별 패턴 분석

```
요일별 패턴을 분석하는 섹션을 추가해줘.

- 요일별 평균 매출 (월~일)
- 요일별 평균 예약 건수
- 주중 vs 주말 비교
- 히트맵 또는 바 차트로 시각화
```

### 옵션 C: 고객 세그먼트 분석

```
고객 세그먼트 분석 섹션을 추가해줘.

- 목적별 (Business/Leisure/Family/Honeymoon) 매출 비중
- 국적별 평균 객단가 비교
- 예약 채널별 평균 숙박 일수
- 각 세그먼트의 특성을 요약 텍스트로 표시
```

### 옵션 D: PDF 보고서 내보내기

```
현재 대시보드 내용을 PDF로 내보내는 기능을 추가해줘.

- "PDF 다운로드" 버튼
- 현재 화면의 KPI + 차트를 포함
- 보고서 제목: "롯데호텔 운영 분석 리포트"
- 생성 날짜 자동 표시
- html2canvas + jsPDF 사용 (CDN)
```
