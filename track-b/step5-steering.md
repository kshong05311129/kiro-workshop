# Step 5: Steering으로 프로젝트 규칙 설정

> 분석 도구의 스타일과 규칙을 문서화합니다.

## 진행 순서

### 1. Steering 생성 요청

Kiro 채팅에 입력:

```
이 프로젝트의 Steering 문서를 생성해줘.

규칙:
- 롯데호텔 브랜드 컬러: 골드(#C5A572), 네이비(#1B2B4B), 화이트
- 차트 컬러 팔레트: 네이비, 골드, 스카이블루(#4A90D9), 코랄(#E8735A)
- 숫자 포맷: 한국 원화 (₩1,234,567), 퍼센트 (소수점 1자리)
- 날짜 포맷: YYYY-MM-DD (한국식)
- 단일 HTML 파일 유지
- CDN만 사용 (npm 없음)
- 다크 모드 기본
- 모든 텍스트 한국어
- 차트 범례 한국어
```

### 2. 효과 확인

Steering 생성 후, 새로운 기능을 요청해보세요:

```
월별 트렌드 차트를 추가해줘
```

→ 자동으로 브랜드 컬러, 한국어 범례, 원화 포맷이 적용됩니다.

### 3. Steering 수정

필요하면 `.kiro/steering/` 폴더의 문서를 직접 편집하거나, 채팅으로 수정 요청:

```
Steering에 "차트 제목은 항상 16px 볼드"를 추가해줘
```

## 왜 유용한가?

| 상황 | Steering 없이 | Steering 있으면 |
|------|--------------|----------------|
| 차트 추가 | 매번 "골드 컬러로 해줘" 반복 | 자동 적용 |
| 숫자 표시 | 어떤 건 ₩, 어떤 건 원 | 항상 ₩ 포맷 |
| 새 기능 | 스타일 들쭉날쭉 | 일관된 디자인 |

## 확인

✅ `.kiro/steering/` 폴더에 문서가 생성되고, 이후 요청에 규칙이 반영되면 성공!
