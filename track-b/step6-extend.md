# Step 6: 실무 확장 & 자유 실습

> 본인 업무에 맞게 확장하거나, 실제 데이터로 테스트해봅니다.

## 아이디어

### 데이터팀

```
자동 알림 기능을 추가해줘.

조건:
- 일일 매출이 전일 대비 20% 이상 감소하면 빨간 경고
- 객실 점유율이 70% 미만이면 주황 경고
- 특정 객실 타입 예약이 0건이면 알림

화면 상단에 알림 배너로 표시해줘.
```

### IT팀

```
이 대시보드를 Python Flask 백엔드로 전환해줘.

- CSV 업로드 API (/api/upload)
- 분석 결과 API (/api/analysis)
- 프론트엔드는 기존 HTML 유지
- 나중에 DB 연동할 수 있도록 구조화
```

### 기획팀

```
경영진 보고용 요약 페이지를 추가해줘.

- 핵심 KPI 3개만 크게 표시
- 한 줄 인사이트 (가장 중요한 발견)
- 인쇄 최적화 (A4 1장)
- "보고서 인쇄" 버튼
```

### 본인 데이터로 테스트

실제 업무 데이터(개인정보 제거)를 CSV로 만들어서 업로드해보세요:
- 매출 데이터
- 예약 통계
- 고객 만족도 설문 결과
- 직원 근무 스케줄

## 실무 적용 계획

| 기존 방식 | Kiro 활용 |
|-----------|-----------|
| 엑셀에서 피벗 테이블 수동 생성 (30분) | CSV 업로드 → 자동 분석 (10초) |
| 차트 수동 생성 & 포맷팅 (20분) | 자동 시각화 (즉시) |
| 보고서 작성 (1시간) | PDF 내보내기 (1클릭) |
| 매번 같은 작업 반복 | 한 번 만들면 재사용 |
