# Step 3: 태스크 실행 & 결과 확인

> Kiro가 대시보드를 만드는 과정을 지켜보고, 완성된 결과를 확인합니다.

## 진행 순서

### 1. Run all tasks 클릭

Spec의 Task List 탭에서 **"Run all tasks"** 클릭

Kiro가 순차적으로 실행합니다:
- ✅ HTML 기본 구조 + CDN 로드
- ✅ CSV 업로드 UI 구현
- ✅ Papa Parse로 CSV 파싱
- ✅ KPI 계산 로직
- ✅ Chart.js 차트 생성
- ✅ 필터 기능
- ✅ 인사이트 요약
- ✅ 스타일링

### 2. 결과 확인

`index.html` 우클릭 → **"Open with Live Server"**

또는 파일을 브라우저에서 직접 열기

### 3. 샘플 데이터로 테스트

1. 브라우저에서 대시보드가 열리면
2. `hotel_operations_april2026.csv` 파일을 드래그앤드롭
3. 자동으로 분석 결과가 표시되는지 확인

### 4. 확인할 것

- [ ] CSV 업로드가 동작하는가?
- [ ] KPI 카드에 숫자가 표시되는가?
- [ ] 차트가 렌더링되는가?
- [ ] 필터가 동작하는가?
- [ ] 원화 포맷(₩)이 적용되는가?

## 문제가 있을 때

Kiro 채팅에서:

```
차트가 안 보여. 콘솔 에러를 확인하고 수정해줘.
```

```
CSV 업로드 후 데이터가 파싱이 안 돼. Papa Parse 설정을 확인해줘.
```

## 확인

✅ CSV 업로드 → KPI + 차트가 표시되면 성공!

> 💡 **팁**: 브라우저 개발자 도구(F12)의 Console 탭에서 에러를 확인할 수 있습니다. 에러 메시지를 그대로 Kiro에게 붙여넣기하면 수정해줍니다.
