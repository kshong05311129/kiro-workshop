# Step 2: Spec으로 대시보드 설계

> Kiro에게 데이터 분석 대시보드를 만들어달라고 요청합니다.

## 진행 순서

### 1. New Spec 클릭

Kiro 패널 → **Specs** 섹션 → **+** 버튼 클릭

### 2. 프롬프트 입력

아래 내용을 복사하여 붙여넣기 합니다:

```
호텔 운영 데이터 분석 대시보드를 단일 index.html 파일로 만들어주세요.

입력: CSV 파일 업로드 (hotel_operations_april2026.csv 형식)

기능:
1. CSV 파일 드래그앤드롭 업로드
2. 데이터 파싱 후 테이블 미리보기 (상위 10건)
3. 핵심 KPI 카드 표시
   - 총 예약 건수
   - 총 매출 (₩ 포맷)
   - 평균 객단가 (ADR)
   - 객실 타입별 비율
4. 차트 시각화
   - 일별 매출 추이 (라인 차트)
   - 객실 타입별 매출 비중 (도넛 차트)
   - 예약 채널별 분포 (바 차트)
   - 국적별 고객 분포 (바 차트)
5. 필터 기능
   - 날짜 범위 선택
   - 객실 타입 필터
   - 예약 채널 필터
6. 요약 인사이트 (텍스트)
   - 가장 매출이 높은 날
   - 가장 인기 있는 객실 타입
   - 주요 고객 국적 Top 3
   - 평균 숙박 일수

기술 조건:
- 단일 index.html 파일
- Tailwind CSS (CDN)
- Chart.js (CDN)
- Papa Parse (CDN, CSV 파싱용)
- 서버 없이 브라우저에서만 동작
- 반응형 디자인
- 다크/라이트 모드 토글
- 숫자는 한국 원화 포맷 (₩1,234,567)
```

### 3. Spec 검토

Kiro가 생성하는 문서를 단계별로 확인합니다:

**① Requirements** — 기능 요구사항 정리 → 확인 후 다음 단계

**② Design** — UI 레이아웃, 차트 배치 설계 → 확인 후 다음 단계

**③ Task List** — 구현 순서 → 확인

## 확인

✅ `.kiro/specs/` 폴더에 Spec 문서가 생성되었으면 성공!
