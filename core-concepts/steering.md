# Steering (스티어링)

> Steering은 AI에게 "우리 프로젝트의 규칙"을 알려주는 가이드 문서입니다.

## 한 줄 요약

**"AI에게 '우리 회사는 이렇게 해'라고 알려주는 사내 규정집"**

## Steering이 뭔가요?

자동차의 핸들(steering wheel)처럼, AI가 올바른 방향으로 가도록 안내하는 문서입니다.

### 비유

신입 직원이 입사하면 사내 규정을 알려주죠?

- "고객에게는 항상 존댓말을 사용합니다"
- "이메일 서명에는 부서명을 포함합니다"
- "보고서는 A4 1장 이내로 작성합니다"

Steering은 AI에게 이런 규칙을 알려주는 것입니다.

## 예시

```markdown
# 프로젝트 규칙

## 디자인
- 롯데호텔 브랜드 컬러 사용 (골드 #C5A572, 네이비 #1B2B4B)
- 폰트는 깔끔하고 읽기 쉬운 것으로
- 모바일에서도 잘 보이도록

## 톤앤매너
- 고객 응대 답변은 정중하고 따뜻하게
- "~입니다", "~드립니다" 체 사용
- 롯데호텔의 품격을 유지

## 기술
- 단일 HTML 파일로 작성
- 외부 라이브러리는 CDN으로 로드
- 한국어 UI 기본
```

## 왜 필요한가요?

| Steering 없이 | Steering 있으면 |
|--------------|----------------|
| AI가 매번 다른 스타일로 작성 | 일관된 스타일 유지 |
| 브랜드 컬러를 모름 | 롯데호텔 컬러 자동 적용 |
| 답변 톤이 들쭉날쭉 | 항상 정중한 톤 유지 |

## 실습에서 직접 해볼 것

4부 실습 Step 5에서:
1. Kiro에게 Steering 문서 생성 요청
2. 프로젝트에 맞는 규칙이 자동으로 정리됨
3. 이후 AI가 이 규칙을 참고하여 코드 작성

> 💡 **핵심**: Steering은 한 번 만들어두면 프로젝트 내내 AI가 참고합니다. "매번 같은 말 반복하지 않아도 되는" 편리한 기능입니다.
