# Specs (스펙)

> Spec은 Kiro에게 "무엇을 만들고 싶은지" 알려주는 문서입니다.

## 한 줄 요약

**"프로젝트 기획서를 AI가 자동으로 작성해주는 기능"**

## Spec이 뭔가요?

여러분이 Kiro에게 "이런 걸 만들어줘"라고 요청하면, Kiro는 바로 코드를 쓰지 않습니다. 대신 3단계 문서를 먼저 만듭니다:

### 1단계: Requirements (요구사항)
"무엇이 필요한가?"를 정리합니다.

```
예시:
- 고객 이메일을 입력받는 텍스트 영역이 필요하다
- 언어를 자동으로 감지해야 한다
- 한국어로 번역된 결과를 보여줘야 한다
- 답변을 생성하는 버튼이 있어야 한다
```

### 2단계: Design (설계)
"어떻게 만들 것인가?"를 설계합니다.

```
예시:
- 화면 왼쪽: 입력 영역
- 화면 오른쪽: 결과 영역
- 상단: 언어 감지 표시
- 하단: 답변 생성 버튼
```

### 3단계: Task List (작업 목록)
"어떤 순서로 만들 것인가?"를 나열합니다.

```
예시:
□ HTML 기본 구조 생성
□ 입력 폼 UI 구현
□ 번역 기능 구현
□ 답변 생성 기능 구현
□ 스타일링 적용
```

## 왜 이렇게 하나요?

| 바로 코드 작성 | Spec 먼저 작성 |
|---------------|---------------|
| AI가 엉뚱한 걸 만들 수 있음 | 계획을 먼저 확인 가능 |
| 수정이 어려움 | 계획 단계에서 수정 쉬움 |
| 결과를 예측할 수 없음 | 무엇이 만들어질지 미리 파악 |

## 실습에서 직접 해볼 것

4부 실습에서 여러분이 직접:
1. Kiro에게 프롬프트 입력
2. 생성된 Requirements 검토
3. Design 확인
4. Task List 승인 → 실행

이 과정을 체험합니다.

> 💡 **핵심**: Spec은 여러분과 AI 사이의 "계약서"입니다. AI가 멋대로 하지 않고, 합의된 계획대로 진행하도록 보장합니다.
