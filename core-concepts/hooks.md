# Hooks (훅)

> Hooks는 특정 이벤트가 발생하면 AI가 자동으로 작업을 수행하는 기능입니다.

## 한 줄 요약

**"파일을 저장할 때마다 AI가 자동으로 검토해주는 비서"**

## Hooks가 뭔가요?

"훅(Hook)"은 "갈고리"라는 뜻입니다. 특정 순간에 자동으로 걸려서 실행되는 작업이에요.

### 비유

호텔에서의 자동화와 비슷합니다:

| 호텔 자동화 | Kiro Hooks |
|------------|-----------|
| 고객 체크인 → 자동으로 환영 메시지 발송 | 파일 저장 → 자동으로 코드 검토 |
| 예약 접수 → 자동으로 확인 메일 발송 | 새 파일 생성 → 자동으로 문서 업데이트 |
| 체크아웃 → 자동으로 만족도 설문 발송 | 코드 변경 → 자동으로 테스트 실행 |

## 어떤 종류가 있나요?

### 파일 저장 시 (On Save)
파일을 저장할 때마다 자동 실행

```
예: 코드를 저장하면 → AI가 자동으로 오류 검사
```

### 파일 생성 시 (On Create)
새 파일이 만들어질 때 자동 실행

```
예: 새 페이지 추가 → AI가 자동으로 목차 업데이트
```

### 수동 실행 (Manual)
버튼을 눌러 직접 실행

```
예: "검토해줘" 버튼 클릭 → AI가 전체 프로젝트 점검
```

## 왜 유용한가요?

- 반복 작업을 자동화
- 실수를 자동으로 잡아줌
- "까먹고 안 한" 작업 방지

## 실습에서 직접 해볼 것

4부 실습에서 Hooks의 동작을 확인합니다. 파일이 변경될 때 Kiro가 자동으로 관련 작업을 수행하는 것을 볼 수 있습니다.

> 💡 **핵심**: Hooks는 "자동 비서"입니다. 여러분이 신경 쓰지 않아도 AI가 알아서 챙겨줍니다.
