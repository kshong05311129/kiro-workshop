# Step 8: 나만의 기능 만들어보기

> 자유롭게 원하는 기능을 추가해봅니다 — 실무에서 필요한 것을 직접 요청하세요!

## 아이디어 예시

아래는 참고용 아이디어입니다. 본인 업무에 맞는 것을 자유롭게 요청해보세요!

### 프론트 데스크

```
체크인 안내 메시지를 자동으로 생성하는 기능을 추가해줘.
고객명, 객실번호, 체크아웃 날짜를 입력하면
환영 메시지를 한국어/영어/일본어/중국어로 생성해줘.
```

### 컨시어지

```
주변 관광지 추천 기능을 추가해줘.
고객이 관심사(쇼핑/문화/음식/자연)를 선택하면
맞춤 추천 리스트를 보여줘.
```

### 예약팀

```
예약 확인 이메일 템플릿 생성 기능을 추가해줘.
고객명, 체크인/아웃 날짜, 객실 타입을 입력하면
전문적인 확인 메일을 생성해줘.
```

### 하우스키핑

```
객실 점검 체크리스트를 추가해줘.
체크 항목을 하나씩 확인하고,
완료되면 보고서를 자동 생성해줘.
```

## 진행 방법

1. 위 예시 중 하나를 선택하거나, 본인만의 아이디어를 생각합니다
2. Kiro 채팅에 자연어로 요청합니다
3. 결과를 확인하고, 마음에 들 때까지 수정 요청합니다

## 공유 시간
