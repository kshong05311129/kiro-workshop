# Step 7: Git으로 저장하기

> 만든 프로젝트를 Git으로 저장(버전 관리)합니다.

## Git이 뭔가요?

"저장" 버튼의 고급 버전이라고 생각하세요. 언제든 이전 상태로 돌아갈 수 있고, 변경 이력을 추적할 수 있습니다.

## 진행 순서

### 1. 터미널 열기

Kiro 상단 메뉴: **Terminal → New Terminal**

또는 단축키: `` Ctrl + ` `` (백틱)

### 2. Git 초기화

터미널에 아래 명령어를 입력합니다:

```bash
git init
```

### 3. 파일 추가 & 저장

```bash
git add .
git commit -m "호텔 고객 응대 도우미 완성"
```

### 4. 확인

왼쪽 사이드바의 소스 제어(Source Control) 아이콘을 클릭하면 저장 이력을 볼 수 있습니다.

[스크린샷: Source Control 패널]

## 왜 하나요?

- 실수로 파일을 망쳐도 이전 버전으로 복구 가능
- 나중에 GitHub에 올려서 다른 사람과 공유 가능
- 변경 이력 추적

## 확인

✅ `git commit` 명령이 성공하면 완료!

> 💡 **팁**: Git이 어렵게 느껴지면 이 단계는 건너뛰어도 됩니다. 실습의 핵심은 Step 2~5입니다.
