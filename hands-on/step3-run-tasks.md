# Step 3: 태스크 실행하기

> Kiro가 작업 목록을 하나씩 실행하며 코드를 작성하는 과정을 지켜봅니다.

## 진행 순서

### 1. 태스크 목록 열기

Spec에서 **"3 Task list"** 탭을 클릭합니다.

또는 왼쪽 사이드바에서 `.kiro/specs/` 아래의 `tasks.md` 파일을 클릭합니다.

[스크린샷: Task list 탭]

### 2. "Run all tasks" 클릭

태스크 목록 상단의 **"Run all tasks"** 버튼을 클릭합니다.

[스크린샷: Run all tasks 버튼]

### 3. 실행 과정 관찰

Kiro가 각 태스크를 순차적으로 실행합니다:

- ✅ HTML 기본 구조 생성
- ✅ 입력 폼 UI 구현
- ✅ 번역 기능 구현
- ✅ 답변 생성 기능 구현
- ✅ 스타일링 적용
- ...

왼쪽 사이드바에 `index.html` 파일이 나타나는 것을 확인하세요.

[스크린샷: 태스크 실행 중 화면]

### 4. Supervised 모드에서의 확인

Supervised 모드에서는 Kiro가 각 변경사항을 적용하기 전에 보여줍니다.

- **Accept** (수락): 변경사항 적용
- **Reject** (거부): 변경사항 취소

> 처음에는 모두 **Accept** 하면서 진행하세요.

## 확인

✅ 왼쪽 사이드바에 `index.html` 파일이 생성되었으면 성공!

> 💡 **팁**: 실행 중에 에러가 나더라도 걱정하지 마세요. Kiro가 자동으로 수정을 시도합니다. 그래도 안 되면 채팅으로 "에러가 났어, 수정해줘"라고 요청하면 됩니다.
