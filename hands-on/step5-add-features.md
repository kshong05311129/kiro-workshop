# Step 5: 기능 추가 요청하기

> 채팅으로 새로운 기능을 추가해봅니다 — AI와 대화하며 도구를 발전시키는 경험.

## 진행 순서

### 1. Kiro 채팅창 열기

Kiro 패널의 **Chat** 섹션을 클릭합니다.

### 2. 기능 추가 요청

아래 중 원하는 것을 선택하여 채팅에 입력하세요 (또는 직접 작성!):

**옵션 A: 답변 템플릿 추가**
```
자주 사용하는 답변 템플릿을 추가해줘.

템플릿 종류:
1. 예약 가능 안내
2. 예약 불가 안내  
3. 체크인/체크아웃 시간 안내
4. 부대시설 안내
5. 불만 응대 (사과 + 조치)

버튼으로 선택하면 자동 삽입되게 해줘.
```

**옵션 B: 긴급 키워드 하이라이트**
```
긴급 처리가 필요한 키워드를 감지하면 빨간색으로 하이라이트 해줘.

긴급 키워드:
- 불만, complaint, クレーム, 投诉
- 취소, cancel, キャンセル, 取消
- 환불, refund, 返金, 退款
- 긴급, urgent, 緊急
```

**옵션 C: 문의 내역 저장**
```
처리한 문의 내역을 화면 하단에 표 형태로 저장해줘.

표시할 정보:
- 시간
- 원문 언어
- 문의 유형
- 요약 (한 줄)
```

### 3. 결과 확인

Kiro가 코드를 수정한 후, 브라우저를 새로고침하여 추가된 기능을 확인합니다.

[스크린샷: 기능이 추가된 화면]

### 4. 추가 수정 요청 (자유)

마음에 들지 않는 부분이 있으면 계속 대화하세요:

- "템플릿 버튼 색상을 골드로 바꿔줘"
- "표에 삭제 버튼도 추가해줘"
- "긴급 키워드 감지되면 소리도 나게 해줘"

## 확인

✅ 새로운 기능이 추가되어 동작하면 성공!

> 💡 **핵심**: 이것이 Kiro의 진짜 힘입니다. 한국어로 원하는 것을 말하면 AI가 코드를 수정합니다. 개발자 없이도 도구를 계속 발전시킬 수 있어요.
