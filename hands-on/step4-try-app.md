# Step 4: 결과 확인하기

> 만들어진 호텔 고객 응대 도우미를 브라우저에서 열어봅니다.

## 진행 순서

### 1. index.html 열기

왼쪽 사이드바에서 `index.html`을 찾아 **우클릭** → **"Open with Live Server"** 선택

또는: `index.html` 파일을 **더블클릭**하여 브라우저에서 직접 열기

[스크린샷: 브라우저에서 열린 앱]

### 2. 샘플 문의로 테스트

아래 샘플 문의를 입력해보세요:

**영어 문의:**
```
Hello, I would like to book a deluxe room for 3 nights 
from July 15th. Do you have availability? 
Also, does the rate include breakfast?
```

**일본어 문의:**
```
7月15日から3泊でデラックスルームを予約したいです。
空室はありますか？朝食は含まれていますか？
```

**중국어 문의:**
```
您好，我想预订7月15日起3晚的豪华房间。
请问有空房吗？房价包含早餐吗？
```

### 3. 기능 확인

각 문의를 입력한 후 확인할 것:

- [ ] 언어가 자동으로 감지되는가?
- [ ] 한국어 번역이 표시되는가?
- [ ] 문의 유형이 분류되는가? (예: "예약 문의")
- [ ] 답변이 자동 생성되는가?
- [ ] 답변이 고객 언어로 번역되는가?
