# Step 6: Steering 문서 생성하기

> 프로젝트 규칙을 문서화하여 AI가 일관되게 작업하도록 합니다.

## 진행 순서

### 1. Steering 생성 요청

Kiro 채팅에 다음을 입력합니다:

```
이 프로젝트의 Steering 문서를 생성해줘.

규칙:
- 롯데호텔 브랜드 컬러 사용 (골드 #C5A572, 네이비 #1B2B4B, 화이트)
- 고객 응대 답변은 정중하고 따뜻한 톤
- "~입니다", "~드립니다" 체 사용
- UI는 한국어 기본
- 단일 HTML 파일 유지
- Tailwind CSS CDN 사용
```

### 2. 생성된 문서 확인

Kiro가 `.kiro/steering/` 폴더에 문서를 생성합니다.

왼쪽 사이드바에서 `.kiro/steering/` 폴더를 열어 확인하세요.

[스크린샷: Steering 문서]

### 3. Steering 효과 확인

이제 Kiro에게 새로운 요청을 해보세요:

```
VIP 고객용 특별 인사말 기능을 추가해줘
```

Kiro가 자동으로:
- 롯데호텔 브랜드 컬러를 적용하고
- 정중한 톤으로 인사말을 작성하고
- 기존 UI 스타일과 일관되게 구현합니다

→ Steering 문서 덕분에 매번 스타일을 지정하지 않아도 됩니다!

## 확인

✅ `.kiro/steering/` 폴더에 문서가 생성되었으면 성공!

> 💡 **핵심**: Steering은 "한 번 설정하면 계속 적용되는 규칙"입니다. 팀원이 같은 프로젝트를 작업해도 일관된 결과를 얻을 수 있습니다.
